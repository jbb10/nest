# Security Policy

## Supported versions

Only the latest release receives security fixes. Releases are cut from `main`
by the automated release pipeline, so a fix merged into `main` ships with the
next release. Older releases are not backported.

| Version | Supported |
| ------- | --------- |
| latest release | yes |
| older releases | no |

## Reporting a vulnerability

Report vulnerabilities privately, not in a public issue. Open the
[Security tab](https://github.com/jbb10/nest/security) and choose
**Report a vulnerability** - GitHub forwards the report privately to the
maintainer.

Include what you can:

- the Nest version (`nest --version` or the release tag)
- a minimal reproduction or proof of concept
- the impact the vulnerability has
